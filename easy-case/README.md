# 醍醐的海岸骑行

一页以原创 SVG 插画呈现的海岸骑行：鹈鹕醍醐骑着自行车，沿晴朗的海边公路前行。画面通过透视、分层光影和连续镜头变化营造 3D 质感。页面使用原生 HTML、CSS 和 JavaScript，无需安装依赖或加载远程素材。

## 本地预览

需要 Python 3。进入 `easy-case/` 后启动静态文件服务器：

```powershell
python -m http.server 4173
```

打开 <http://localhost:4173>。

## 交互

- **停下喝口水**：播放一次海边补水动作，然后恢复触发前的播放状态。
- **暂停动画 / 继续动画**：控制骑行、镜头和环境动画；也可以在页面空白处按空格键。
- 页面尊重系统“减少动态效果”设置；手动补水仍可触发。

需求、设计决策和浏览器验收步骤见 [`specs/003-taigu-seaside-ride/`](specs/003-taigu-seaside-ride/)。
