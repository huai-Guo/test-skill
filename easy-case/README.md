# 河岸小歇：鹈鹕的饮水时间

一页以原创 SVG 插画呈现的河岸观察：一只鹈鹕在浅滩边停下来喝水。页面使用原生 HTML、CSS 和 JavaScript，无需安装依赖，也不加载远程素材。

## 本地预览

需要 Python 3。启动静态文件服务器：

```powershell
python -m http.server 4173
```

打开 <http://localhost:4173>。

## 交互

- **看鹈鹕喝水**：手动播放一次俯身饮水动作，然后回到之前的播放或暂停状态。
- **暂停动画 / 继续动画**：控制鹈鹕和河岸的动画，也可以在页面空白处按空格键。
- 页面尊重系统“减少动态效果”设置；核心画面不依赖远程资源。

需求和浏览器验收步骤见 [`specs/002-pelican-water-scene/`](specs/002-pelican-water-scene/)。
