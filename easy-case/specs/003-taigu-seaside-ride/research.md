# Research: 醍醐的海岸骑行

## 当前行为

- `index.html` 的页面文案、SVG 主体、按钮和补充说明都描述鹈鹕河岸饮水；SVG 角色为鹈鹕，因此现有视觉不能满足骑行需求。
- `app.js` 管理鹈鹕饮水定时、手动动作、暂停/继续、空格键及 `prefers-reduced-motion`。新页面应保留这些交互能力，重写角色动作与场景文案。
- 旧版 `feat/taigu-cycling-water` 把醍醐画成人类骑行者；用户指出不希望拟人，也明确表示旧版不满意，因此不沿用其角色造型、配色或版式。本轮按用户补充把醍醐确定为鹈鹕，并采用自然鹈鹕身体、长喙、喉囊、羽翼和蹼足。
- Constitution 要求原创本地 SVG、桌面及窄屏浏览器检查、交互可访问、减少动态效果以及专用分支不合并。

## 设计决策

### 插画而非真实 3D

- **决策**：保持 SVG 矢量场景，通过透视收敛线、比例层次、渐变明暗、投影、轮廓高光、海面闪光和景深表现立体感。
- **原因**：用户已选择 3D 质感矢量插画，项目 Constitution 也要求静态依赖最少；真实 WebGL 会引入对单页效果不必要的技术与性能成本。

### 海岸画面和镜头编排

- **决策**：以低机位三分之四跟拍为主要构图，展示弧形海岸线、前景公路及中景角色；页面采用深海色全幅旅志版式，与旧版浅色双栏卡片区分。用远景建立、跟拍、轮组/路面特写、补水停顿、继续骑行组成循环。
- **原因**：单一侧视循环难以传达空间和分镜设计；可读的镜头阶段让“酷炫”有具体视觉依据。

### 新角色和配色

- **决策**：将鹈鹕放在自行车上，以翼尖搭车把、蹼足踩踏板表达动作；鸟体保持完整的羽毛躯干与鹈鹕喉囊，不添加衣服、头盔、背包或人类手臂结构。采用栗褐与乳白羽色、金黄长喙、珊瑚色喉囊、蓝绿自行车，与深海蓝页面背景形成新视觉系统。
- **原因**：用户明确排除了拟人造型，并指出旧版整体体验不满意，必须重新设计角色和页面视觉。

### 动画和状态

- **决策**：SVG 分层通过 CSS transform/opacity 做车轮、踩踏、角色起伏、海浪、光斑、路面视差与镜头状态；JavaScript 负责播放状态、补水动作和 aria-live 文案。
- **原因**：保持现有静态页面和用户控制能力，避免逐帧脚本或新增依赖。

### 浏览器验证

- **决策**：使用真实浏览器检查桌面与 360 px；观察三个周期、暂停/继续、补水、键盘、减少动态效果、控制台及网络资源。
- **原因**：画面构图和分镜质量不能只靠源码审查验证。
