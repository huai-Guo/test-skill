# Feature Specification: 鹈鹕河岸饮水动画

**Feature Branch**: `feat/pelican-water-animation`
**Created**: 2026-09-24
**Status**: Implemented
**Input**: 用户希望优化仓库中的喝水展示动画，将原骑行人物改为动物鹈鹕，并改善网页视觉表现。

## User Scenarios & Testing

### User Story 1 - 观看鹈鹕饮水场景 (Priority: P1)

访客打开页面后，能立即看到一只鹈鹕在河岸边饮水。画面具有明确的前景、背景和空间层次，鹈鹕外形与饮水动作容易辨认。

**Independent Test**: 浏览器打开页面后，五秒内能识别鹈鹕、河岸环境和饮水主题；连续观察场景动画，动作自然且循环衔接。

**Acceptance Scenarios**:

1. **Given** 页面已加载，**When** 访客看到主视觉，**Then** 画面主体是一只原创插画风格的鹈鹕，而不是骑车人物。
2. **Given** 自动播放开启，**When** 鹈鹕完成一次饮水动作，**Then** 鹈鹕俯身触水、抬头吞咽并恢复休息姿态，周边水面有轻微回应。
3. **Given** 页面在窄屏打开，**When** 访客浏览主视觉和控件，**Then** 主体和主要内容仍清楚可见且无横向溢出。

### User Story 2 - 控制饮水动画 (Priority: P2)

访客可以暂停或继续场景，并手动触发鹈鹕饮水动作。

**Independent Test**: 使用鼠标、触屏或键盘操作动画控件，确认动画、按钮文案和状态提示一致。

**Acceptance Scenarios**:

1. **Given** 场景正在播放，**When** 访客暂停，**Then** 场景中的持续动画停止并显示继续操作。
2. **Given** 页面已打开，**When** 访客手动触发饮水，**Then** 饮水动作播放一次，之后回到先前播放或暂停状态。
3. **Given** 系统启用减少动态效果，**When** 页面加载或设置改变，**Then** 不自动播放持续动画，静态画面和手动控件仍可用。

## Requirements

### Functional Requirements

- **FR-001**: 主视觉 MUST 使用鹈鹕动物角色和河岸饮水主题，移除骑车人物内容。
- **FR-002**: 饮水动画 MUST 清楚呈现俯身触水、吞咽和复位动作，并循环平顺。
- **FR-003**: 访客 MUST 能暂停和继续动画，也 MUST 能手动触发一次饮水动作。
- **FR-004**: 手动动作完成后 MUST 恢复触发前的播放状态。
- **FR-005**: 页面 MUST 尊重系统减少动态效果偏好，并保留静态内容与控件。
- **FR-006**: 页面 MUST 在桌面和窄屏保持可读、可操作且无横向溢出。
- **FR-007**: 交互控件 MUST 支持键盘操作并提供可访问名称及当前状态。
- **FR-008**: 页面 MUST 无需远程图片、字体、脚本或服务端即可完整展示。

## Success Criteria

- **SC-001**: 首屏明确显示鹈鹕、河岸和饮水主题。
- **SC-002**: 浏览器中可连续完成至少三次饮水循环，动作无卡住或明显跳变。
- **SC-003**: 暂停、继续、手动饮水和空格快捷键均产生正确状态。
- **SC-004**: 360 CSS 像素视口下无水平页面溢出，主按钮可触达。
- **SC-005**: 减少动态效果开启时无持续自动动画，控件和内容仍可使用。

## Assumptions

- 访客所说的动物指鹈鹕；角色采用原创插画，不依赖外部图片素材。
- 项目继续使用独立 HTML、CSS 和原生 JavaScript 的静态页面结构。
- 视觉方向采用温暖、清爽的河岸自然色彩，突出鹈鹕和水面动作。
